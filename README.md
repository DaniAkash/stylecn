# Shadcn-theming

A workbench for shadcn/ui theming experiments.

## Experiments

- **apple-shadcn** — bringing Apple's design language to shadcn/ui

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- shadcn/ui (radix base, nova preset)
- React Router
- bun

## Develop

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```
